# 💅 Clari Nails Shop

Sitio web y catálogo digital oficial para **Clari Nails**, un espacio dedicado a la estética, cuidado y diseño de uñas. Diseñado para que las clientas puedan ver los servicios, explorar productos, ver la ubicación exacta del local y realizar pedidos o consultas directas a través de WhatsApp de forma rápida y sencilla.

## 🚀 Enlace al sitio web
Podés visitar la página en línea haciendo clic aquí:  
👉 [https://cbenegas1.github.io/ClariNailsshop/](https://cbenegas1.github.io/ClariNailsshop/)

---

## ✨ Características principales
* **Pop-up de bienvenida:** Anuncio especial al ingresar a la web (configurado para mostrarse una sola vez por sesión).
* **Catálogo interactivo con Carrito:** Permite seleccionar productos/servicios y calcular subtotales.
* **Integración con WhatsApp:** Envío de pedidos estructurados y automáticos directo al chat del local.
* **Ubicación Interactiva:** Mapa de Google Maps integrado y datos de contacto/horarios.
* **Diseño Responsive:** Adaptado perfectamente para celulares, tablets y computadoras.
* **Optimización SEO:** Configurado con metadatos para buscadores y redes sociales (Open Graph).

---

## 🛠️ Tecnologías utilizadas
* **HTML5** (Estructura semántica)
* **CSS3** (Diseño moderno, estilos y adaptabilidad)
* **JavaScript (Vanilla)** (Lógica del carrito, pop-up y generación de enlaces de WhatsApp)
* **FontAwesome** (Iconografía)
